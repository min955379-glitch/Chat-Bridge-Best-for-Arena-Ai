Chat Bridge

Make two AI chats talk to each other, automatically.

The one-minute version. Pick the chat box, the send button and the AI reply in each tab, press Make this Tab A / Make this Tab B, choose how many rounds, press Start.

1. Pick the three spots

  1. Click the Chat Bridge icon while the chat tab is active.
  2. Press Pick chat box, then click inside the page's message box.
  3. Press Pick send button, then click the send arrow.
  4. Press Pick AI reply, then click the AI's answer. Press ↑ once or twice so the blue box covers the whole answer, then click.
  5. Press Test copy: the first 200 characters of the newest answer should appear. Press Test paste: the word test appears in the chat box and is not sent.

While picking, the page shows a toast with the keys:

  • ↑ bigger area (the parent element)
  • ↓ back again
  • click to save
  • Esc to cancel

Picks are saved per site and per first path part, so arena.ai/c and arena.ai/agent keep their own picks.

2. Choose the tabs

  1. In the first chat tab, open the popup and press Make this Tab A.
  2. Open the second chat tab and press Make this Tab B.

The popup only ever talks about the tab that is active when you open it. The same tab cannot be both A and B.

Best results: put the two chat tabs in two separate Chrome windows side by side. Chrome slows down tabs it cannot see, and some sites refuse pasted text in a tab that is not being looked at.

3. Copy modes

ModeWhat is forwarded
Full replyThe whole answer.
Last code blockThe newest <pre><code> block only.
Between markersOnly the text between START and END. This is the best way to keep two AIs on topic.

Prefix and suffix are added around every forwarded message. Example prefix: Here is the other AI's answer. Improve it.

4. Waiting until the AI is finished

Chat Bridge reads the newest answer once a second. The answer counts as started when the text (or the number of replies) changes, and as finished when it has not changed for the seconds of silence you set.

Arena agent pages: set seconds of silence to 20–30. Agents go quiet while they run tools, and a low value would forward a half-finished answer.

5. Safety options

  • Max rounds safety limit — a hard cap (default 100).
  • Stop if the new reply is identical to the previous one — catches two AIs repeating the same sentence.
  • Stop when the reply contains — for example DONE.
  • Stop — stops immediately, also in the middle of a wait.

6. API mode (optional)

Instead of a second chat tab, one side can be Google Gemini or xAI Grok.

  1. Settings → Mode → Tab and API.
  2. Paste the Gemini and/or Grok API key. They are stored only in this browser.
  3. Choose the main provider. The other one becomes the automatic backup.

On a rate limit (HTTP 429), a rejected key, a server error, a network problem or an empty answer, Chat Bridge retries once after 2 seconds and then switches to the backup provider. A provider that hit 429 rests for 60 seconds. The log says which provider answered.

7. Smart Helper (optional)

Three optional helpers that use your Gemini or Grok key with the same automatic fallback. They are off by default, and Tab to Tab mode works with no keys at all.

  • Auto detect brain and worker — reads the last reply and the last user message of both tabs, asks the API which window plans (the brain) and which one does the work (the worker), then sets the brain as Tab A and the worker as Tab B. The result is shown in plain words. You can always change it by hand with the Make this Tab A / B buttons. If the answer is unclear, nothing is changed.
  • Pick the best answer — when a chat shows several answer cards for the newest turn, all of them are read and the API picks the best one for your project goal. Only that card is forwarded. With one answer no API call is made.
  • Auto stop when done — type the project goal. After every round (or every N rounds) the API is asked whether the project is finished. On DONE the loop stops and the reason appears in the status line.

Safety: a hard limit of helper calls per run (30 by default), only the last few messages are sent, keys never appear in a message or in the log, and a failed helper call is logged while the normal loop carries on. The log names the provider that answered every call.

Note: the Smart Helper is the only part of Chat Bridge that sends your chat text to Google or xAI. With the switch off, nothing leaves this computer beyond the API mode requests you already chose to make.

8. Common problems

MessageWhat to do
Chat box not foundClear the picks and pick the three spots again.
The chat box stayed empty after pastingClick directly inside the message box when picking.
Timed out waiting for Tab BUse two Chrome windows, raise seconds of silence, raise the timeout.
The answer is cut in halfRe-pick the AI reply and press ↑ so the whole answer is covered.
No code block foundThe answer has no code. Change the copy mode.
I could not find the START markerTell the AI to wrap its message between your marker words.
Run was interruptedChrome restarted the extension in the background. Press Start again.
API key was rejectedCopy the key again; make sure it belongs to that provider.
Smart Helper: no API key is savedAdd a Gemini or Grok key in Settings, or switch the helper off.
Smart Helper: used all its callsRaise Max helper calls per run. The normal loop still works.

Nothing is sent anywhere except the API requests you turn on: API mode, and the Smart Helper when you switch it on. All picks and settings live in this browser.
